## 1. 角色定义（先定死）

宏观情境层只做三件事：

1. **归因**｜持仓/指数异动时，先做共性检验（大盘/板块/同业是否同向），区分"市场风浪"与"标的自身问题"。结论必须由数据支撑，不允许事后编叙事。
2. **触发复核**｜§4 的少量硬触发器命中后，产出 1 页复核备忘（证据 → 涉及持仓 → 动作路线）。
3. **情景标注**｜在报告中为持仓标注宏观情景敏感性，用于预期管理。

**红线（非目标）：**

- 不产出买卖信号；不做点位/事件预测。
- 与 P/S 分位体系各司其职；两者信号冲突时不得混用。
- 触发器只生成"复核"动作；复核若指向调仓，走既有纪律（估值档位 / 止损线 / 分批计划 / 8% 红线）。
- 事件窗口原则：宏观层的作用是让纪律更稳，而不是给临场操作提供素材。

## 4. 触发器清单（v0.1，阈值待校准）

**口径规则**：一律以收盘价/结算价 + 连续 2 个交易日确认；盘中瞬时穿越不作为触发。

### T1 美联储信号剧变（两侧）

- **触发**：FOMC 决议 + 点阵图/措辞显著偏离市场定价。
  - 鹰派情形：点阵图显示年内还需 ≥1 次加息，或声明为连续加息留门；
  - 鸽派情形：意外按兵不动，或明确排除后续加息。
- **复核**：美股试水账户步进节奏（Step2/Step3 时点）；成长仓（芯片ETF / 宁德）估值假设；组合整体风险预算。
- **备注**：首次检验 2026-09-17。

### T2 油价失控上沿

- **触发**：Brent 期货结算价 > $120（超过 3 月战争高点 ≈119.5）。
- **复核**：能源敏感链（芭田成本传导 / 金风相对竞争力 / 比亚迪 EV 替代经济学）；输入性通胀对国内政策空间的约束；全球风险偏好。

### T3 油价溢价回吐

- **触发**：Brent 期货结算价 < $85，或霍尔木兹"实质复航"（协议正式签署 / 通行量连续恢复）。
- **复核**：反向复核 T2 链条；复盘所有"假设地缘溢价持续"的判断；更新情景概率。

### T4 人民币急动

- **触发**：USDCNY 单周变动 ≥1.0%（暂定）。
- **复核**：外资敏感持仓、港股映射。
- **背景**：当前 ≈6.71，2023 年 1 月以来最强——继续走强需下调"外资流出"叙事权重；急贬才是状态切换信号。

### T5 美国通胀/就业极端值

- **触发**：核心 CPI 环比 ≥0.4% 或 ≤0.1%；或非农偏离市场预期 >5 万（暂定）。
- **复核**：全球利率路径假设（含美股账户）；成长估值压力评估。

**暂缓项**：国内政策类（降准降息、经济数据大幅偏离）只进快照"事件"行，不设硬触发器——防止清单膨胀；两周后评估是否补充。
